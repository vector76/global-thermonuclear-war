Launch the backend:
```
cd backend ; python -m app.main
```

List users:
```
cd backend ; python -m scripts.manage_admin list
```

Add admin privileges to user:
```
cd backend ; python -m scripts.manage_admin add vector76@gmail.com
```

List missiles:
```
cd backend ; python -m scripts.list_missiles
```

Launch the frontend:
```
cd frontend ; npm start
```
