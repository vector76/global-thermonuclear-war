Launch the backend:
```bash
cd backend
python -m app.main
```

List users:
```bash
cd backend
python -m scripts.manage_admin list
```

Add admin privileges to user:
```bash
cd backend
python -m scripts.manage_admin add vector76@gmail.com
```

List missiles:
```bash
cd backend
python -m scripts.list_missiles
```

Launch the frontend:
```bash
cd frontend
npm run dev
```
